# Supply Chain & Logistics Analytics

## Overview

This project focuses on analyzing supply-chain and logistics operations using the
DataCo Smart Supply Chain dataset.

The project is being developed as part of my YuvaIntern internship, with the goal
of exploring logistics data, identifying delivery-performance patterns, and
developing analytical insights that can support future predictive and
optimization tasks.

## Week 1 – Strategic Planning & Data Exploration

The Week 1 analysis focuses on:

- Dataset structure and exploration
- Data-quality assessment
- Missing-value analysis
- Duplicate detection
- Descriptive statistics
- Delivery-performance analysis
- Shipping-mode analysis
- Market and regional analysis
- Order-volume trends
- Initial business insights

## Dataset

Dataset: DataCo Smart Supply Chain for Big Data Analysis

The dataset contains 180,519 records and 53 variables covering:

- Orders
- Customers
- Products
- Shipping
- Delivery
- Markets
- Sales
- Profit

## Key Week 1 Findings

- 180,519 records and 53 variables
- 0 duplicate records
- Product Description has 100% missing values
- Order Zipcode has 86.24% missing values
- Late delivery risk rate: 54.83%
- Average actual shipping time: 3.50 days
- Average scheduled shipping time: 2.93 days
- Schedule breach rate: 57.28%
